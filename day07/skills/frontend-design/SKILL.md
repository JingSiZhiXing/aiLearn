# Frontend Design Skill
 
当用户请求创建网页、前端组件或 UI 界面时，遵循以下原则：
 
## 核心原则
1. **视觉独特性**：避免通用 AI 风格，每个设计都应有独特的视觉个性。
2. **代码质量**：输出生产就绪的 HTML/CSS/JS 或 React 代码。
3. **响应式设计**：默认支持移动端和桌面端。
4. **无障碍访问**：遵循 WCAG 标准，确保可访问性。
 
## 技术规范
- HTML: 语义化标签，正确的 meta 标签
- CSS: CSS 变量管理主题，Flexbox/Grid 布局
- JS: 原生 JS 优先，必要时使用框架
- React: 函数组件 + Hooks，Tailwind CSS 样式
 
## 设计要求
- 选择有特色的字体（避免 Arial, Inter 等通用字体）
- 使用有主张的配色方案
- 加入适当的动画和微交互
- 注重空白和排版节奏
